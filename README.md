# Kyle Joyce Portfolio Website

This is a static, responsive one-page engineering portfolio designed to be linked from job applications, LinkedIn, resumes, and networking messages.

## Files
- `index.html` — all page content
- `styles.css` — layout and visual design
- `script.js` — mobile menu, current year, copy-email interaction
- `resume.pdf` — add your actual resume using this exact filename

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html`.
2. Replace `https://www.linkedin.com/in/YOUR-LINKEDIN`.
3. Add your resume to this folder as `resume.pdf`.
4. Optional: add GitHub, project screenshots, or a headshot later.

## Easiest hosting options
### GitHub Pages
Create a repository, upload these files, then enable GitHub Pages in the repository settings.

### Netlify
Drag the entire folder into Netlify's deploy area.

### Vercel
Import the folder/repository as a static site.

## Recommended public URL
A custom domain like `kylejoyce.dev`, `kylejoyce.engineer`, or `kylejoyce.me` makes the link look much stronger on applications.
